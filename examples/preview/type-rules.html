Type rules at a glance
✓ Segoe UI only
No other typeface in app UI
✓ Sentence case
Never ALL-CAPS labels

Bold only for H4–H6
✓ Bold for emphasis
Never underline or italic
✓ Narrow columns
Long lines tire the eye
✗ No widows/orphans
