Component library

Every component as a token-built CSS class — no React, no web-component library, no build step. Link colors_and_type.css then components.css, copy the markup, wire behaviour with Alpine.

Stack: HTML + CSS + inline Alpine Link: colors_and_type.css → components.css Icons: fluent-basic-icons.svg (ic-fluent-*)
How to read this page. Each specimen shows the live component on top and its exact markup below — hit Copy and paste. Interactivity (open, toggle, sort, filter) is yours to wire in inline Alpine; see example-advanced-ui.html for the same classes composed into a full page.

Icons

Self-hosted Fluent sprite (fluent-basic-icons.svg, ids ic-fluent-{name}-24-regular). .icon inherits currentColor; use the size helpers (12 / 16 / 20 / 24 only). Inline the sprite once per page so same-document #id refs resolve.

Two SVG forms, one name token. The no-JS form needs only the two CSS files + the inlined sprite — a dev not ready for our scripting is never blocked. The optional sugar form <fluent-icon> needs one script tag (fluent-icon.js). Both resolve to the same ic-fluent-* symbol, so you can mix them and migrate between them mechanically. A third delivery — the first-party Fluent icon font (<i class="icon-ic_fluent_home_24_regular" aria-hidden>) — gives the full Fluent set with no sprite and no JS; aria-hidden the <i> and size via font-size. See the technical reference §6.

Reveal-on-scroll script
Drop once per page. Adds .is-in to each .reveal as it enters the viewport; respects reduced-motion and degrades to fully-visible without JS.
<script>
  (function () {
    var reduce = matchMedia('(prefers-reduced-motion: reduce)').matches;
    var els = document.querySelectorAll('.reveal');
    if (reduce || !('IntersectionObserver' in window)) {
      els.forEach(function (el) { el.classList.add('is-in'); }); return;
    }
    var io = new IntersectionObserver(function (entries) {
      entries.forEach(function (e) {
        if (e.isIntersecting) { e.target.classList.add('is-in'); io.unobserve(e.target); }
      });
    }, { threshold: .12, rootMargin: '0px 0px -8% 0px' });
    els.forEach(function (el, i) {
      el.style.transitionDelay = (Math.min(i % 5, 4) * 45) + 'ms';
      io.observe(el);
    });
  })();
</script>
