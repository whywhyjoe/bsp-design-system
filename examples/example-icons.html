Icons, every method

Four ways to put an icon on a page. Each section shows the same icons done that way, what the page needs once, and the markup to copy. Every icon below sits in text colored --fg-primary — watch which ones follow it.

Which one?

Start with the sprite. Reach for the font when the sprite doesn't have the icon. Use Abacus for BMO brand icons.

1 · Sprite <use> — the default

No JavaScript. Points at a symbol in the sprite by name. A name with no symbol renders blank.

<!-- once: paste the whole fluent-basic-icons.svg as the first thing in <body> -->

<svg class="icon icon--24" aria-hidden="true"><use href="#ic-fluent-home-24-regular"/></svg>
<button class="btn btn--secondary">
  <svg class="icon icon--16" aria-hidden="true"><use href="#ic-fluent-mail-24-regular"/></svg> Email
</button>

2 · <fluent-icon> — same sprite, shorter markup

Optional. A small script turns the element into the method 1 markup, so it uses the same sprite and the same names.

<!-- once: the sprite (as in method 1) + this script -->
<script src="/sites/FCUPortal/Code/bsp-design/fluent-icon.js" defer></script>

<fluent-icon name="home-24-regular" class="icon--24"></fluent-icon>
<button class="btn btn--secondary">
  <fluent-icon name="mail-24-regular" class="icon--16"></fluent-icon> Email
</button>

3 · Icon font — every Fluent icon

No sprite, no JavaScript. The Resizable font has every Fluent icon, outline (_regular) and solid (_filled). Names always use _20_; set the size with font-size. Link only this one icon-font stylesheet.

<!-- once, in <head> -->
<link rel="preload" href="/sites/FCUPortal/Code/fluent-icons/fonts/FluentSystemIcons-Resizable.woff2" as="font" type="font/woff2" crossorigin>
<link rel="stylesheet" href="/sites/FCUPortal/Code/fluent-icons/fonts/FluentSystemIcons-Resizable.css">

<i class="icon-ic_fluent_home_20_regular" aria-hidden="true" style="font-size:24px"></i>
<i class="icon-ic_fluent_mail_20_filled" aria-hidden="true" style="font-size:24px"></i>
<button class="btn btn--secondary">
  <i class="icon-ic_fluent_mail_20_regular" aria-hidden="true" style="font-size:16px"></i> Email
</button>

4 · Abacus <img> — BMO brand icons

No setup. Point an <img> at the file. The colors are part of the file, so they stay blue here even though the text color is dark.

<!-- no setup — alt="" when decorative, real alt text when the icon carries meaning -->
<img class="icon icon--24" src="/sites/FCUPortal/Code/bsp-design/abacus-icons/home-24.svg" alt="">
<button class="btn btn--secondary">
  <img class="icon icon--16" src="/sites/FCUPortal/Code/bsp-design/abacus-icons/mail-24.svg" alt=""> Email
</button>
